- Activation à vie : **500 DZD en un seul paiement**, sans abonnement mensuel.
- Une connexion Internet est nécessaire uniquement lors de la première activation. Le code de 16 caractères est à usage unique et lié au premier appareil Android qui l’active.

- Export PDF arabe/français avec un modèle de résumé sur deux pages et l’historique des manches ; les tournois longs peuvent continuer sur des pages supplémentaires. Police arabe Amiri.

- Les données des tournois restent sur le téléphone et ne sont pas transmises au service d’activation.
- Cette version ne contient ni publicité, ni SDK d’analyse ou de suivi. L’unique permission réseau est `INTERNET`, utilisée pour l’activation HTTPS initiale ; WhatsApp ne s’ouvre que si vous choisissez de contacter le développeur.

### Migration depuis la version de test 1.0.4

La version de test 1.0.4 utilisait la clé de signature Android de débogage ; Android ne peut donc pas installer la version officielle 1.0.5 comme mise à jour directe. Avant de désinstaller la version de test, exportez les données des tournois en JSON depuis les paramètres. Désinstallez ensuite la version de test, installez l’APK officiel et restaurez la sauvegarde. Le changement de clé modifie l’identifiant de l’application sur Android ; un code déjà utilisé avec la version de test peut nécessiter un code de remplacement fourni par le développeur.
