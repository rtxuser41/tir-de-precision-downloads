### Migration depuis la version de test 1.0.4

La version de test 1.0.4 utilisait la clé de signature Android de débogage ; Android ne peut donc pas installer la version officielle 1.0.5 comme mise à jour directe. Avant de désinstaller la version de test, exportez les données des tournois en JSON depuis les paramètres. Désinstallez ensuite la version de test, installez l’APK officiel et restaurez la sauvegarde. Le changement de clé modifie l’identifiant de l’application sur Android ; un code déjà utilisé avec la version de test peut nécessiter un code de remplacement fourni par le développeur.
